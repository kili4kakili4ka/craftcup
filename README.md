# CraftCup — кофейня с онлайн-заказом

Веб-приложение для заказа кофе с интерактивным конструктором напитков.

## Возможности
- Конструктор напитка: объём, молоко, сироп, доп. шоты
- Пересчёт цены в реальном времени
- Корзина с сохранением конфигурации
- Предзаказ с выбором точки и времени
- Личный кабинет с привязанными картами

## Стек
- Frontend: Vanilla JS, HTML5, CSS3
- Backend: Node.js, Express
- База данных: SQLite (better-sqlite3)
- Аутентификация: JWT

## Установка и запуск

1. Клонировать репозиторий:
   git clone https://github.com/kili4kakili4ka/craftcup.git
   cd craftcup/backend

2. Установить зависимости:
   npm install

3. Запустить сервер:
   node server.js

4. Открыть в браузере:
   http://localhost:4000

## Структура проекта
- `backend/` — Node.js API и база данных
- `frontend/` — HTML, CSS, JS-файлы интерфейса

## API
| Метод | Путь | Описание |
|---|---|---|
| POST | /api/auth | Вход по телефону + имени |
| GET | /api/menu | Меню из базы данных |
| GET | /api/cards | Карты пользователя |
| POST | /api/cards | Добавить карту |
| DELETE | /api/cards/:id | Удалить карту |
| POST | /api/orders | Создать заказ |
